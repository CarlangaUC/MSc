# data/ (local, no versionar)

Carpeta para artefactos grandes regenerables o de trabajo local.

Ejemplos típicos:

- `listas_wikipedia_zdd_versionadas.txt`
- dumps intermedios, `.docs` / `.zpack` temporales

Todo el directorio está en `.gitignore` salvo este README (si se trackea a mano).
**No hagas `git add data/`.**

Entrada canónica del pipeline: `uiHRDC/.../data/texts/` y `datos_sinteticos/`.
